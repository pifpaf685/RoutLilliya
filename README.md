# Lilly Rout — сайт-візитівка

Німецькомовний статичний сайт. У папці `dist/` є HTML, CSS, JavaScript, фото, відео й іконка. Залежностей і кроку збірки немає.

## Перегляд

Відкрийте `dist/index.html` або запустіть у папці проєкту:

```sh
python3 -m http.server 8080 --directory dist
```

Відкрийте http://localhost:8080.

## Для Codex

Тексти й прайс — у `dist/index.html`, стилі — у `dist/style.css`, мобільне меню, відео та підготовка листа для запису — у `dist/app.js`. Вибір послуги бере ціни з таблиць у HTML. `DESIGN.md` містить задум і нотатки з перевірки.

Опублікована версія доступна на https://lillyrout.at/. У сайті відновлено 20 цін з оригінального прайсу `source-assets/originals/IMG_2086.PNG`, додано мобільний педикюр від 65 € залежно від відстані та уніфіковано контакти. Користувач підтвердив адресу прийому: Brandstätte 3/1 St/6, Wien. Її додано в контакти та Impressum; повні юридичні реквізити власниці ще потрібно доповнити. Datenschutz оновлено відповідно до фактичної конфігурації аналітики. Для хостингу використовуйте вміст `dist/` як корінь сайту.

## Структура та публікація

- `dist/` — лише файли, потрібні публічному сайту; це коренева папка для хостингу. Збірка не потрібна.
- `source-assets/originals/` — початкові фото й відео; `source-assets/unused-variants/` — варіанти зображень, які сайт зараз не використовує.
- `archive/legacy-worker/wrangler.jsonc` — конфігурація видаленого Worker, збережена лише для довідки. Не запускайте її повторно: сайт працює через GitHub Pages.

Цільовий репозиторій — https://github.com/pifpaf685/RoutLilliya, домен — `lillyrout.at`. Попередній репозиторій `pifpaf685/lilly-rout` залишено окремо, а старий Worker `lilly-rout-pedicure` видалено 8 листопада 2026 року після перевірки роботи домену через GitHub Pages. Не підключайте сайт до Worker або репозиторію Jonas. Юридичні дані, зазначені вище, поки не заповнені.

Сайт публікується через GitHub Pages із `dist/` після змін у гілці `main`. DNS домену обслуговує Cloudflare; HTTPS для відвідувачів працює через проксі Cloudflare. Окремий сертифікат GitHub Pages для домену ще не підтверджено, тому перед вимкненням проксі його потрібно перевірити. Локальні зміни не переходять на публічний сайт автоматично, доки їх не внесено в репозиторій та не виконано публікацію.

## Поточний напрямок

Оновлена версія акцентує на уважній Fußpflege для особливих потреб: окремий блок показує конкретні послуги з прайсу та пояснює межу між доглядом і лікарською допомогою. Зображення `dist/assets/foot-care-detail-v2.jpg` — згенерована ілюстративна деталь за реальним робочим фото, а не документальний кадр процедури. В Австрії назву `medizinische Fußpflege` для звичайної Fußpflege вживати не слід; формулювання сайту це враховують.

Головний портрет `dist/assets/lilly-rout-professional-bg.jpg` створено на основі наданого користувачем зображення із цифрово зміненим фоном. На сторінці це позначено біля фото. Початкове реальне фото `dist/assets/lilly-rout.jpg` і відео залишені без змін; новий фон не слід трактувати як документальне зображення фактичного приміщення.

## Аналітика

Google Analytics 4 і Tag Manager налаштовано 8 листопада 2026 року. `dist/tracking.js` завантажує GTM лише після згоди на статистику; рекламні дозволи залишаються відхиленими. Деталі та перевірені результати: `ANALYTICS_SETUP.md`. Перевірка логіки згоди: `node --test tests/tracking.test.cjs`.
